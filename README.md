# 🎨 AI Neural Style Transfer using PyTorch & Flask

This project implements Neural Style Transfer using PyTorch and deploys it with Flask. It transforms an input image by combining its content with the artistic style of another image.

## Features
- Neural Style Transfer
- Image Upload
- Flask Web Application
- PyTorch Deep Learning Model
- User-friendly Interface

## Technologies Used
- Python
- PyTorch
- Flask
- OpenCV
- HTML
- CSS
